# AI Agents Hackathon 2026

## Build the Future with AI Agents

Artificial Intelligence is evolving beyond models into autonomous systems capable of reasoning, decision-making, and real-world execution. **AI Agents Hackathon 2026** brings together developers, researchers, founders, and innovators to build the next generation of intelligent systems powered by modern AI infrastructure.

Organized by **HackIndia**, India’s largest hackathon series, this hackathon is designed for builders exploring AI agents, automation, large language models, retrieval systems, evaluation pipelines, and real-world AI applications at scale.

Participants will work on impactful problems across productivity, healthcare, finance, language technology, automation, and open innovation while collaborating with mentors, ecosystem partners, and leading AI companies.

## 💰 Challenge Tracks & Prizes

### 1️⃣ Adaptive Data Track — Sponsored by Adaption

> **Special Track Sponsor ($2,000 Prize Pool!)**
> Adaption is building infrastructure for the next generation of AI systems through Adaptive Data — a platform designed to help developers ingest, adapt, evaluate, and export high-quality datasets for AI agents, fine-tuning pipelines, and real-world AI applications.
> The platform enables builders to create dynamic, multilingual, and domain-specific datasets that improve AI system performance across underserved languages, industries, and use cases. Adaptive Data currently supports **242 languages**.

* **Track Focus:** Building intelligent AI systems powered by dynamic, real-world datasets and multilingual AI infrastructure. Participants must demonstrate meaningful integration and usage of the Adaptive Data platform within their project.
* **Perk:** All eligible participants will receive **500 Adaption credits** at the beginning of the hackathon to build using the platform.
* **Suggested Problem Statements:**
* Build an AI agent for a low-resource language using Adaptive Data, where the dataset continuously improves through user feedback and corrections.
* Build domain-specific evaluation agents for sectors such as healthcare, legal, agriculture, or financial compliance using Adaptive Data-powered evaluation pipelines.



🎁 **Prizes:**

* **1st Place:** $1,000 USD from Adaption
* **2nd Place:** $600 USD from Adaption
* **3rd Place:** $400 USD from Adaption
*(Note: Winning teams will receive prize money directly from Adaption via their registered email address.)*

## 📝 Submission Requirements

### 🔹 Adaptive Data Track Requirements

* Submit the Adaption dataset using the official submission form: [https://uc9yb.share.hsforms.com/2VyQDViA5RQOCS3ydhGF6mA](https://uc9yb.share.hsforms.com/2VyQDViA5RQOCS3ydhGF6mA)
* Open-source the dataset on **Hugging Face** and **Kaggle**.
* Credit Adaption within the dataset description and README documentation.
* Demonstrate active usage of the Adaptive Data platform within the project.
* *Projects that do not meaningfully integrate Adaptive Data may not be considered eligible for the Adaption prize pool.*

### 🔹 Sharp Economy Track Requirements (HackIndia Main Track)

* Submit complete project code through the official HackIndia GitHub submission workflow.
* Include a **2-minute demo video** explaining the product and technical implementation.
* Submit project details, architecture, and setup instructions.
* Demonstrate a functional prototype or working AI workflow.
