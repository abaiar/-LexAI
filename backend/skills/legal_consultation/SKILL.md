# Skill: 通用法律咨询

## Description
通用法律咨询服务，覆盖民事、商事、行政等各领域法律问题咨询。

## Trigger_Conditions
当用户提出通用法律问题，不特定于劳动、婚姻、合规等专项领域时使用。

## Core_Laws
- 《中华人民共和国民法典》
- 《中华人民共和国合同法》
- 《中华人民共和国民事诉讼法》

## Default_Keywords
- 民法典
- 合同法
- 法律咨询

## Output_Format
总分总结构，包含【适用法规】【相似类案】【法律建议】三个部分。

## Execution_Steps
1. 分析用户问题，判断是否需要检索案例或法规
2. 如需案例支撑，调用案例检索工具并引用真实案例
3. 如需法条依据，调用法规检索工具获取相关法律条文
4. 综合以上信息，给出结构清晰的法律分析报告

## Acceptance_Criteria
- 必须引用至少1条具体法规条款（如需检索）
- 严禁编造案例编号或引用不存在的法条
- 回答要专业、准确、有条理

## Forbidden_Behaviors
- 编造案例编号
- 引用不存在的法条
- 提供非中国法律的回答
