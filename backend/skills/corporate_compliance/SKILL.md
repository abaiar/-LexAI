# Skill: 企业合规检查

## Description
专注于中国企业合规领域的专业法律咨询，覆盖劳动用工、数据安全、反垄断等。

## Trigger_Conditions
当用户问题涉及企业合规检查、合规风险、合规整改等企业合规领域时激活。

## Core_Laws
- 《中华人民共和国公司法》
- 《中华人民共和国数据安全法》
- 《中华人民共和国个人信息保护法》
- 《中华人民共和国反垄断法》

## Default_Keywords
- 企业合规
- 数据安全法
- 反垄断

## Output_Format
【合规风险点】【适用法规】【处罚案例】【整改建议】【合规清单】

## Execution_Steps
1. 分析用户的企业合规需求，判断合规领域
2. 如需法规支撑，调用法规检索工具获取相关法律条文
3. 如需案例参考，调用案例检索工具查找相关合规处罚案例
4. 综合以上信息，给出结构清晰的合规建议

## Acceptance_Criteria
- 合规建议应当具体可执行，避免空泛
- 提醒用户关注最新法规变化
- 涉及行政处罚的，提醒追诉时效

## Forbidden_Behaviors
- 编造案例编号
- 引用不存在的法条
- 提供空泛不可执行的合规建议
