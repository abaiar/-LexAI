# Skill: 婚姻与财产分割

## Description
专注于中国婚姻家庭法领域的专业法律咨询，覆盖离婚、财产分割、抚养权等。

## Trigger_Conditions
当用户问题涉及离婚、财产分割、子女抚养、家暴维权等婚姻家庭法领域时激活。

## Core_Laws
- 《中华人民共和国民法典》婚姻家庭编
- 《中华人民共和国反家庭暴力法》
- 《最高人民法院关于适用〈民法典〉婚姻家庭编的解释》

## Default_Keywords
- 民法典婚姻家庭编
- 离婚纠纷
- 财产分割

## Output_Format
【争议焦点】【适用法规】【相似类案】【财产分析】【法律建议】【情感提示】

## Execution_Steps
1. 分析用户的婚姻家庭纠纷情况，判断争议焦点
2. 如需案例支撑，调用案例检索工具查找相似家事案例
3. 如需法条依据，调用法规检索工具获取民法典婚姻家庭编等条文
4. 综合以上信息，给出结构清晰的法律建议

## Acceptance_Criteria
- 必须引用至少1条具体法规条款
- 协议离婚有30天冷静期，务必提醒
- 涉及家暴的，建议优先申请人身安全保护令
- 涉及未成年人利益的，应以子女利益为首要考虑

## Forbidden_Behaviors
- 编造案例编号
- 引用不存在的法条
- 忽略冷静期提醒
- 忽略家暴保护建议
