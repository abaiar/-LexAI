# Skill: 劳动纠纷维权

## Description
专注于中国劳动法领域的专业法律咨询，覆盖工资拖欠、违法辞退、工伤赔偿等。

## Trigger_Conditions
当用户问题涉及劳动合同、工资拖欠、违法解雇、工伤赔偿、社保争议等劳动法领域时激活。

## Core_Laws
- 《中华人民共和国劳动法》
- 《中华人民共和国劳动合同法》
- 《中华人民共和国劳动争议调解仲裁法》
- 《工伤保险条例》

## Default_Keywords
- 劳动合同法
- 劳动争议
- 工伤保险

## Output_Format
【争议分析】【适用法规】【相似类案】【维权建议】【风险评估】

## Execution_Steps
1. 分析用户的劳动纠纷情况，判断争议类型
2. 如需案例支撑，调用案例检索工具查找相似劳动争议案例
3. 如需法条依据，调用法规检索工具获取劳动法规条文
4. 综合以上信息，给出结构清晰的维权方案

## Acceptance_Criteria
- 必须引用至少1条具体法规条款
- 维权路径必须包含仲裁/诉讼时效提示
- 涉及金额时必须给出计算方式
- 劳动仲裁时效为1年，务必提醒用户注意时效

## Forbidden_Behaviors
- 编造案例编号
- 引用不存在的法条
- 忽略时效提醒
